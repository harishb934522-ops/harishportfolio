September 2026 · Full-stack + microservices

Multi-Language Code Plagiarism & Logic Contradiction Engine

An explainable code-analysis platform that detects structural similarity and simple logic contradictions in Java and Python student submissions. Tutors get transparent evidence and the final academic decision always stays with a human.

  • Parses both languages into a shared AST-based intermediate representation so similarity is compared structurally, independent of variable names.
  • A Node.js/Express API gateway orchestrates Python (FastAPI) and Java microservices for cross-language comparison, known-algorithm fingerprinting and Python logic-contradiction checks.
  • Role-based Student and Tutor workflows with Clerk authentication, a Monaco code editor, a side-by-side diff viewer, an interactive similarity graph and Gemini-generated readable reports, backed by MongoDB.
React Node.js Express MongoDB FastAPI Java Clerk Gemini

How the analysis works

  1. Source code
  2. Language parser
  3. AST
  4. Shared IR
  5. Structural comparison
  6. Algorithm fingerprint
  7. Contradiction check
  8. Report formatting
